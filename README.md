# Snake Game 🐍

This is a simple snake game I built a few years ago using plain JavaScript, HTML, and CSS — no libraries or frameworks involved. It was one of my early web dev projects to explore DOM manipulation and basic game loops.

It’s a classic grid-based snake game with arrow key controls, local high score saving, and some basic sound effects. Everything runs entirely in the browser.

## ▶️ Play the Game

**[Play on GitHub Pages](https://prix007.github.io/SnakeSaga-WebD/)**

---

## How to Play

- Use your **arrow keys** to control the snake.
- Eat the red square (food) to grow and increase your score.
- Don’t hit the wall or your own tail — that ends the game.
- Your high score is stored in your browser using `localStorage`.

---

## Controls

- ⬆️ Arrow Up — Move Up  
- ⬇️ Arrow Down — Move Down  
- ⬅️ Arrow Left — Move Left  
- ➡️ Arrow Right — Move Right

---

## Features

- Simple grid-based movement using CSS Grid
- Snake grows with each food item eaten
- Collision detection for walls and self
- High score is stored locally
- Background music and sound effects for actions
